# Algorithms

This directory is reserved for reusable, tested implementations or implementation guidance.

Principle:

- Skills decide **what job to perform**.
- Knowledge explains **what methods mean and when they fit**.
- Algorithms provide **deterministic implementations** when reuse is valuable.

Do not add an algorithm merely because it is popular. Add it when:

1. it is repeatedly used in competitions,
2. the implementation can be tested,
3. inputs and outputs are well defined,
4. failure modes are documented.

Initial suggested modules for later versions:

- regression,
- evaluation,
- graph theory,
- mathematical programming,
- time series,
- grey system,
- Monte Carlo,
- metaheuristics.
