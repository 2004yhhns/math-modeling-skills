# Shared Modeling Knowledge

This directory stores reusable mathematical-modeling knowledge shared by multiple skills.

Use it for **what a method is, when it applies, assumptions, strengths, weaknesses, validation, and failure modes**.

Do not store skill-specific SOPs here. Those belong under `skills/<skill>/references/`.

Organization is by problem family rather than a flat list of algorithms:

- `prediction/`
- `classification/`
- `optimization/`
- `evaluation/`

Later versions may add statistics, simulation, graph/network, mechanism models, time series, and uncertainty.
