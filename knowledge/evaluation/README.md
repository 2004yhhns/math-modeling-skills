# Evaluation and Ranking Knowledge

Use for comprehensive evaluation, ranking, and multi-criteria decision problems.

## Baselines

- equal-weight standardized score,
- simple weighted sum.

## Candidate methods

- entropy weighting,
- TOPSIS,
- AHP,
- PCA-based evaluation,
- fuzzy comprehensive evaluation,
- DEA when efficiency is the true question.

## Key risks

- indicator direction errors,
- scale effects,
- arbitrary weights,
- correlated indicators,
- rank instability,
- confusing ranking with causal explanation.

## Validation

Perform weight sensitivity, method comparison, and rank-stability checks whenever final decisions depend on small score differences.
